# Устав проекта «БРС-Студент»

## Основание для разработки
Задание на рейтинговую работу по дисциплине «Проектная деятельность в ИТ»,
вариант «Р»: разработка программы учета и анализа балльно-рейтинговой системы студентов.

## Назначение
Автоматизация учета баллов, набранных студентами по контрольным точкам дисциплин,
и анализа успеваемости учебной группы.

## Цель проекта
Создать программу, которая хранит баллы студентов, рассчитывает итоговый рейтинг
и формирует аналитические сводки для преподавателя и деканата.

## Заинтересованные стороны
- заказчик — деканат факультета;
- пользователи — преподаватели, сотрудники деканата, студенты;
- команда проекта — руководитель, аналитик, разработчик, тестировщик.

## Модель жизненного цикла
Каскадная модель с промежуточным контролем: инициация, анализ требований,
проектирование, реализация, тестирование, внедрение, сопровождение.
