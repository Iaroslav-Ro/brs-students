# Категории пользователей и права доступа

## Участники проекта в репозитории GitHub

| Роль | Уровень доступа GitHub | Ветки, в которые разрешена запись |
|---|---|---|
| Руководитель проекта | Admin | все; слияние в `main` |
| Системный аналитик | Write | `stage/1-initiation`, `stage/2-analysis` |
| Архитектор | Write | `stage/3-design` |
| Разработчик | Write | `stage/4-implementation` |
| Тестировщик | Write | `stage/5-testing` |
| Инженер внедрения и сопровождения | Maintain | `stage/6-deployment`, `stage/7-maintenance` |
| Заказчик (деканат) | Read | — |

Ветка `main` защищена: изменения попадают в нее только через запрос на слияние
(pull request) из `develop` после проверки руководителем проекта.
Ответственные за каталоги закреплены в файле `.github/CODEOWNERS`.

## Пользователи программы

| Категория | Права |
|---|---|
| Сотрудник деканата | ведение студентов, групп и дисциплин; все отчеты |
| Преподаватель | ввод баллов по своим дисциплинам; отчеты по дисциплине |
| Студент | просмотр собственных баллов и места в рейтинге |
