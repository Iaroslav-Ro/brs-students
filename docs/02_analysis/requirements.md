# Требования к программе «БРС-Студент»

## Функциональные требования
1. Вести список студентов с указанием учебной группы.
2. Вести список дисциплин и контрольных точек с максимальным баллом.
3. Регистрировать баллы студента за контрольную точку; балл не может
   быть отрицательным и не может превышать максимум контрольной точки.
4. Рассчитывать итоговый балл студента по дисциплине (0–100).
5. Переводить итоговый балл в оценку:
   85–100 — «отлично», 70–84 — «хорошо», 50–69 — «удовлетворительно», менее 50 — «неудовлетворительно».
6. Формировать рейтинг студентов группы по среднему итоговому баллу.
7. Формировать статистику по дисциплине: средний, минимальный, максимальный балл,
   доля успевающих.
8. Формировать список студентов с риском неаттестации.

## Нефункциональные требования
- язык реализации — Python 3.9 и выше, без сторонних библиотек;
- хранение данных — файл формата JSON в кодировке UTF-8;
- интерфейс — командная строка;
- покрытие расчетных функций модульными тестами.
