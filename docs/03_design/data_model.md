# Модель данных

## Сущности
- **Студент**: идентификатор, ФИО, группа.
- **Дисциплина**: код, название, список контрольных точек.
- **Контрольная точка**: код, название, максимальный балл.
  Сумма максимальных баллов контрольных точек дисциплины равна 100.
- **Оценка**: идентификатор студента, код дисциплины, код контрольной точки, балл.

## Формат файла JSON
```
{
  "students":    [{"id": "s1", "name": "...", "group": "..."}],
  "disciplines": [{"code": "PD", "title": "...",
                   "checkpoints": [{"code": "kt1", "title": "...", "max_score": 20}]}],
  "scores":      [{"student": "s1", "discipline": "PD", "checkpoint": "kt1", "value": 18}]
}
```
