# Архитектура программы

Программа состоит из четырех модулей пакета `src/brs`:

| Модуль | Назначение |
|---|---|
| `models.py` | классы предметной области: студент, контрольная точка, дисциплина, журнал |
| `storage.py` | загрузка и сохранение журнала в файл JSON |
| `analysis.py` | расчет итоговых баллов, оценок, рейтинга и статистики |
| `cli.py` | интерфейс командной строки |

Зависимости направлены в одну сторону: `cli` → `analysis` → `models`, `cli` → `storage` → `models`.
Модуль анализа не обращается к файлам, что позволяет проверять его модульными тестами.
