# БРС-Студент

Программа учета и анализа балльно-рейтинговой системы (БРС) студентов.

Учебный ИТ-проект по дисциплине «Проектная деятельность в ИТ».

## Возможности

- учет студентов, дисциплин и контрольных точек;
- ввод баллов за контрольные точки с проверкой максимума;
- расчет итогового балла и оценки по 100-балльной шкале;
- рейтинг студентов группы и статистика по дисциплине;
- список студентов с риском неаттестации.

## Запуск

